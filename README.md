# Income Stratification within the Informal Sector
### A Heterogeneous-Agent Incomplete-Markets Approach for Emerging Economies

**Giuliana Triberti** | MA Thesis, Computational Social Science | University of Chicago, 2025

---

## Overview

This repository contains the full replication pipeline for a continuous-time 
Huggett model that explicitly disaggregates the informal sector into 
high-income (IH) and low-income (IL) workers. The model is calibrated to 
Argentina using EPH microdata and compares two-state and four-state 
specifications across structural experiments and policy reform analysis.

The central finding is that treating the informal sector as a homogeneous 
low-income group introduces systematic directional errors into equilibrium 
predictions and policy evaluation — errors that matter for the fiscal 
arithmetic of formalization reform in Argentina.

└── 7. extension_HI_Informals.ipynb    # Phi-sweep extension: varying informal

## Data

The empirical estimates use microdata from Argentina's **Encuesta Permanente 
de Hogares (EPH)**, quarterly panel 2016–2025, available from INDEC:

> https://www.indec.gob.ar/indec/web/Institucional-Indec-BasesDeDatos

Download the quarterly individual files and place them in `1. data/input_data/` 
before running the R scripts.

---

## How to Replicate

Run the scripts in order:

**Step 1 — Data preparation (R)**
```r
source("0. clean_data.R")
source("0. descriptive_analysis.R")
```

**Step 2 — Transition intensity estimation (R)**
```r
source("1. lambda_intensities.R")
source("2. galindo_lambdas_2state.R")
source("2. galindo_lambdas_4state.R")
source("2. galindo_lambdas_phisweep.R")   # run last; requires 4state output
```

**Step 3 — Equilibrium models (Python/Jupyter)**

Open and run notebooks in order:
1. `3. equilibrium_2state_peru.ipynb`
2. `4. equilibrium_2state_arg.ipynb`
3. `5. equilibrium_4state_arg.ipynb`
4. `6. final_visualizations.ipynb`
5. `7. extension_HI_Informals.ipynb`

## Model Summary

| Feature | Specification |
|---|---|
| Framework | Continuous-time Huggett (Aiyagari–Bewley–Huggett) |
| States | 2-state: Informal / Formal |
| | 4-state: IH, IL, FH, FL |
| Preferences | CRRA with state-dependent risk aversion |
| Taxes | Asymmetric: τ_I = 0, τ_FH = 0.19, τ_FL = 0.05 |
| Frictions | Borrowing premium for informal workers (θ_I = 0.02) |
| Calibration | EPH panel 2016–2025, INDEC national accounts, OECD |
| Solution method | Finite differences (HJB + Fokker–Planck) + bisection |
